#### TeX vs LaTeX
- TeX is the actual language along with the low-level primitives it provides to write documents
- It has:
	- Variables
	- Functions (called macros)
	- Conditionals
	- Loops
	- Token processing
- But it is extremely tedious to write documents in pure TeX from scratch
- LaTeX is a collection of macros commands written in TeX which make it easy for us to write documents
- Think of TeX as the actual language and LaTeX as one of the standard libraries which makes life easier when using TeX

You write LaTeX code which describes the structure of a document

A LaTeX compiler compiled the code into desired output format (for me it's .pdf)

LaTeX code is written in the form of commands which look something like this:

```latex
\<command_name>[optional args]{required args}
\documentclass{article}
```


A proper document needs some essential things.

These things depend on the kind of document you are writing

These are provided by document class files (extension .cls)

e.g: article.cls

To include these things we execute the command `\documentclass{<class name>}`
Some valid classes are:
- article
- book
- report
- letter
