

#### `pwd`
- `pwd` stands for "print working directory"

- Does exactly that, prints the absolute path to the current working directory you are in to `stdout`

- There is both a `pwd` shell builtin and a `/usr/bin/pwd` binary


#### `cd`
- `cd` stands for change directory.
- it is a shell builtin.
- no separate binary program since the command is supposed to change the state of the shell it is executed in.
- There are the main usages of `cd`

Syntax:
```bash
#1
cd <path to directory>
# path can be absolute or relative, will cd into it

#2
cd
# No arguement will change the working directory to the home directory of the user that is logged into the shell

#3
cd -
# Will change into the previous directory you were in before you were in the current direcotry you are in right now.

eg:
$ cd /some/random/ahh/path
$ cd ~/DSA
$ pwd
/home/duznoj/DSA
$ cd -
$ pwd
/some/random/ahh/path
$ cd
$ pwd
/home/duznoj
```
